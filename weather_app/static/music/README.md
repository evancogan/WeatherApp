# Channel Audio

_Work in progress, check back later._

- Drop `.mp3 .ogg .wav .m4a .flac` files here. They play in alphabetical order, looped.
- `soundeffect.mp3` (or `power-on` / `poweron`) plays once on **TUNE IN** instead.
- Audio files are git-ignored.
- Packaged `.exe` builds use a `music/` folder next to the executable instead of this one.
